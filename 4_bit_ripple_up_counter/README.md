# 4-Bit Ripple Up Counter using T Flip-Flops

## Description
This project implements a 4-bit asynchronous ripple up counter using T flip-flops constructed from D flip-flops in Verilog HDL.

## Modules
- D Flip-Flop
- T Flip-Flop
- 4-Bit Ripple Counter
- Testbench

## Tools Used
- Icarus Verilog
- GTKWave
- VS Code
