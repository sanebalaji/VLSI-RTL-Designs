# SR Latch using Verilog HDL

## Overview
This project implements an SR Latch using NAND gates in Verilog HDL.

## Files
- RTL/sr_latch.v → RTL Design
- TB/sr_latch_tb.v → Testbench
- WAVEFORMS/sr_latch.vcd → Simulation waveform dump
- SCREENSHOTS/sr_waveform.png → GTKWave output

## Tools Used
- Icarus Verilog
- GTKWave

## Functionality
- Set operation
- Reset operation
- Hold condition
- Invalid condition

## Simulation
Waveforms verified successfully using GTKWave.
